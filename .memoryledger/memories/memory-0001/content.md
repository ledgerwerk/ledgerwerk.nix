When adding or updating packages in ledgerwerk.nix, use package directories under packages/<name>/ with default.nix calling ./package.nix and passing flake. Python CLI tools use python3Packages.buildPythonApplication with pyproject = true, fetchPypi or fetchurl, setuptools, setuptools-scm, and wheel. Runtime deps commonly include flake.packages.${stdenv.hostPlatform.system}.ledgercore plus typer, click, pyyaml, jinja2, markdown-it-py, and tomli as declared by upstream metadata. Regenerate README package docs with ./scripts/generate-package-docs.py, then run nix fmt and validate with nix flake check --accept-flake-config path:$PWD when new package directories are still untracked.
